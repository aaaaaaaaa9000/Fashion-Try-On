# غرفة القياس

تطبيق بيلبّس الهدوم بالذكاء الاصطناعي (جيميناي) على صورتك أو على مانيكان جاهز:

- ارفع صورتك ويتعمل منها صورة موديل نضيفة، أو استخدمها زي ما هي، أو اختار مانيكان (عادي أو مقاس كبير).
- ارفع صور القطع (صورة المنتج لوحده) ودوس عليها عشان تتلبس فوق بعض بالترتيب.
- لو جيميناي رفض قطعة على صورة شخص حقيقي (بيحصل غالبًا مع الملابس الداخلية)، يظهر زرار يجرّبها على المانيكان بضغطة.
- تغيير لون آخر قطعة، تغيير الوضعية، تغيير الخلفية، تحميل الصورة، وحفظ الأطقم على الجهاز.

مفتاح جيميناي بيفضل على السيرفر بس، ومش بيوصل للمتصفح.

## التشغيل على الجهاز

```bash
npm install
cp .env.example .env   # وحط المفتاح
npm run dev            # http://localhost:3000
```

## متغيرات البيئة

| المتغير | لازم؟ | الافتراضي | الوصف |
|---|---|---|---|
| `GEMINI_API_KEY` | أيوه | | مفتاح جيميناي |
| `GEMINI_IMAGE_MODEL` | لأ | `gemini-3.1-flash-lite-image` | موديل الصور لكل الخطوات |
| `APP_USERNAME` | لأ | `user` | اسم المستخدم للدخول |
| `APP_PASSWORD` | لأ | فاضي | لو اتحط، التطبيق يفتح صفحة دخول (مدير كلمات السر يقدر يملاها) |
| `SESSION_DAYS` | لأ | `180` | مدة بقاء الدخول على الجهاز بالأيام |
| `SESSION_SECRET` | لأ | فاضي | مفتاح توقيع الجلسة (الافتراضي مشتق من الباسورد) |
| `RATE_LIMIT_PER_MINUTE` | لأ | `10` | أقصى عدد طلبات في الدقيقة لكل جهاز |
| `MAX_IMAGE_MB` | لأ | `8` | أقصى حجم للصورة المرفوعة |
| `MAX_TEXT_CHARS` | لأ | `300` | أقصى طول للوضعية أو الخلفية المكتوبة |
| `APP_DOMAIN` | لأ | `tryon.aaaaaaaaa9000.cloud` | الدومين في إعدادات ترافيك |

## الرفع على السيرفر (بورتينر)

1. في بورتينر: Stacks ← Add stack ← Repository.
2. الاسم: `ai-app-tryon`، الريبو ده، الفرع `refs/heads/main`، الملف `docker-compose.yml`.
3. حط متغيرات البيئة فوق (على الأقل `GEMINI_API_KEY` و`APP_PASSWORD`).
4. فعّل التحديث التلقائي كل 24 ساعة.

التطبيق بيشتغل على بورت 3000 جوه الكونتينر، وترافيك بيوصله بالدومين مع شهادة أمان تلقائية.
فحص الصحة: `GET /api/health`.
